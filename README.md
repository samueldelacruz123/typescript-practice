# Overview

This software allows me to demonstrate how to use Typescript in:

Display output to the terminal - displays an edited variable and the result of a simple computing function

Recursion - One function adds the digits while the other counts how many digits in an input. And both are displayed in the terminal. This also includes throwing and handling exceptions.

Classes with lists/arrays - Created a book inventory system that uses principles of classes and lists or arrays.

Asynchronous functions - Created async/await functions and records the time used that is significantly faster than a regular function call.
